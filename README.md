# Metrum Models

AI-assisted 3D asset authoring for Metrum Rise — building exteriors and
props, generated by driving Blender through an MCP (Model Context
Protocol) server and refined against reference imagery.

## What this is

An AI agent connects to a local Blender instance over MCP, builds a mesh
interactively using reference imagery for proportions and style, and
checks its own work via rendered views. The result is a low-poly,
game-ready exterior shell — no interiors, no rigging, no animation —
exported as four `.glb` LOD tiers sharing one set of external PNG textures
(albedo, ORM, a normal map, and an emission mask for lit windows at night). Colour
variants are texture swaps on the same geometry.

Two asset classes are defined:

- **Buildings** — exterior shells: massing, roofline, facade texture.
- **Props** — street furniture and lighting (benches, bins, bollards,
  mailboxes, planters, lamp posts).

## Status

Ten buildings are finished and listed in [`CATALOG.md`](CATALOG.md):
six residential (four Finnish post-war houses and two terraces), two
commercial (a corner grocery and a small shopping centre), one service
building (a civic hall with a clock tower) and one industrial (a brick
workshop-and-office block with flat-roofed wings). No props have been built yet;
their conventions and budgets are specified and waiting for the first one.

## Requirements

- **Blender 5.2 or newer** — the catalog's `.blend` files are saved in 5.2
  and will not open in older versions.
- **Git LFS** — every `.blend`, `.glb` and `.png` is stored in LFS.
- **Python with numpy, scipy and Pillow** — for the texture generators
  (supersampled atlases with normal maps and weathering, via
  `scripts/atlas.py` and `scripts/weathering.py`) and the review scripts that
  run outside Blender. shapely is available for 2D plan work.
- The Blender MCP addon is needed only for interactive authoring; builds,
  validation and review renders all run headless.

To check an asset's exports from the repository root:

```bash
blender --background --python scripts/validate_asset.py -- buildings/residential/rintamamiestalo_porch
```

## Repository layout

```text
buildings/<category>/<asset_name>/   # residential, commercial, industrial, service
props/<category>/<asset_name>/       # street_furniture, lighting
scripts/                             # shared helpers: atlas rasteriser, weathering, build pipeline, glazing, emission wiring, validation, review renders
```

Each asset folder holds its Blender source, build and texture scripts,
exported `.glb` tiers and textures, a `notes.md`, a `preview.png`
thumbnail and, for night-lit buildings, a day/night `variants.png`. See
`CLAUDE.md`'s Repository Structure section for the exact shape.

Two folders are local only and git-ignored: `reference/` for reference
imagery, which is never committed, and `review/` for working review
renders.
